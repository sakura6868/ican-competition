# 智能教育网页界面

更新：2026-10-15。本轮按电脑浏览器交付和验收，重点是教师备课与学员实训。

## 已完成

- 学习总览：课程入口、继续上次练习、个人近期记录、教师备课入口。
- 课程中心：课程卡片、搜索、可练习/待准备筛选、课程选择与画面授权。
- 实训课堂：左侧学习路径、中间摄像头与逐条件反馈、右侧步骤示范与标准参考图。
- 教师工作室：教学素材上传、SOP 课程编排、示范预览和发布前校对指引。
- 统一登录、导航、白色面板、紫色主色、按钮与表单；教师入口仍受角色权限控制。
- 首页统计来自课程与个人最近最多 30 次练习；没有加入虚构课程、评分、排名或学员数量。

课程是否可练习取决于教师校对、示范片段和完成条件；AI 服务缺少配置时会单独提示。
识别、进度推进与教师确认仍由原有后端规则处理。

## 开源来源

实际适配了 [Sakai Vue](https://github.com/primefaces/sakai-vue) 的布局及导航状态管理，
以及 [Frappe Learning](https://github.com/frappe/lms) 的课程卡片结构。
保留本项目的 Vue、登录、API 和 SOP 数据模型，并为教学场景重新制作本地样式与抽象封面。

具体原文件、修改范围和 SHA-256 见 [第三方说明](../frontend/THIRD_PARTY_NOTICES.md)。
MIT 与 AGPL-3.0 原文已包含在 `frontend/LICENSES/`，页面底部“开源与许可”也可查看。

## 在电脑上打开

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-tutor.ps1 -SkipInstall
```

浏览器打开 <http://127.0.0.1:5185>，使用本机已创建的账号登录。
首次安装时去掉 `-SkipInstall`。账号初始化与 API 配置见 [陪练使用说明](SOP_TUTOR_README.md)。

教师流程：教学素材 → 编排课程 → 校对步骤、示范片段和完成条件 → 发布。

学员流程：课程与 AI 陪练 → 选择课程并授权工作区画面 → 开始课程 → 看示范并操作。
