# 参赛版开发日志：2026-10-13 至 2026-10-15

## 目标

把已有的预录视频考评系统转成智慧教育闭环：教师将完整教学视频发布为 SOP 课程，学生跟随示范逐步练习，系统按教师确认的条件核验并反馈。

## 主要实现

- 建立教学模式 SOP：步骤教学片段、参考时间点、结构化核验条件、纠错提示和教师确认门禁。
- 建立持久化练习状态机：暂停恢复、并发修订号、幂等观察、SSE 反馈、证据引用和调用上限。
- 普通步骤改为一次三帧核验；三帧覆盖至少 1 秒并含不同图像。关键/安全步骤保留两轮独立确认。
- 增加未知结果自动补拍与 4/8/12/15 秒退避，减少无效 API 调用。
- 增加学生学习报告和教师班级学情看板；指标由持久化状态和 Provider 收据计算。
- 增加课程元数据和最新发布版本筛选，避免把内部 `process_key` 当课程名。
- 增加可重置的一键赛场环境、预置工程回放和 API 故障说明。
- 完成鞋带、折纸杯、单套结三个跨场景公开视频技术验证；均为同源回放，不作为真人准确率。

## 验证证据

- 鞋带普通步骤 API 平均 3.24 秒；一次遮挡不前进，四步依次完成。
- 折纸杯 15 个固定输入与预期状态一致，最终完成五步。
- 单套结验证了两轮新画面和人工条件门禁，未完成全课程。
- 后端当前产品测试、Ruff、Mypy及前端测试/构建在提交前执行，结果写入最终交付说明。

## 历史测试处理

源码包保留了十个旧数据集适配测试文件，但对应 `gongxu.data` 实现已不在源码包，远端初始仓库也没有可恢复内容。这些测试属于 Assembly101、IndustReal 和 IMPACT 数据摄取实验，不参与当前教师发布—学生陪练产品路径。参赛版将它们列为历史实验测试，不将其冒充为已实现能力。
