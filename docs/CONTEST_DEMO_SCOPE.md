# 比赛演示范围：模块小车装配实训

> 2026-10-15 更新：最终演示范围和五分钟脚本见 `CONTEST_FINAL_README_2026-10-15.md` 与 `CONTEST_DEMO_SCRIPT_5MIN.md`；模块小车是历史首发方案。

## 已确定的首发场景

产品以“模块小车/履带机器人装配实训”为首发演示工序。它对应项目内的公开
IndustReal v2 装配参考视频和已发布的 `industreal_v2_assy_validation` SOP；不再为
演示临时编造没有视频、来源或评分标准支撑的新工序。

场景边界：单人、单工作台、固定机位、9 个部件安装步骤。标准视频作为 SOP 的
来源证据，学员视频进入同一套加密资产、Qwen 关键帧分析、规则对齐和报告流程。

## 可直接演示的产品闭环

1. 教师进入 SOP 工作台，展示标准视频/来源证据和可编辑步骤。
2. 展示每步三类条件：动作语义、完成状态、可观察安全规范。
3. 发布 SOP 后，学员在“视频考评”选择该 SOP 并上传已授权操作视频。
4. 后端仅向 Qwen 发送必要压缩关键帧；本地规则生成步骤时间线、证据、分数和改进建议。
5. 对正常装配样本，展示步骤覆盖与完成状态证据；状态不够清晰时系统显示“无法判断”。
6. 展示离线工程回放的完整操作、明确错工具和证据不足三种交互。该入口固定标识
   `fixture_replay`，只用于产品行为演示，不作为真实模型指标。

## 诚实的能力边界

- 已验证：Qwen 调用、加密视频资产、SOP 对齐、步骤报告、可信拒判与缓存隔离可以
  端到端运行。
- 已有正常样本的 9/9 步动作状态匹配结果，但一些最终装配状态仍需拒判。
- 未验证：细微孔位、朝向、销钉与紧固关系错误的可靠自动检出。此类情况在当前版本
  应返回“需复核/证据不足”，不能在答辩中宣称自动纠错成功。
- 不宣称工业安全认证、生产级准确率或专家替代。

## 下一轮材料采集规格

为把比赛演示从“流程完整”提升为“可稳定评分”，后续只需围绕本场景采集授权视频：

- 3 至 5 段完整正确操作；
- 2 段漏装或错工具等画面中明显可见的错误；
- 2 段遮挡、远景或中断样本，用于展示可信拒判；
- 每段同时保留全景和部件近景，且在录制前固定机位和工位边界。

这些视频由系统自动哈希、抽帧、预标注和生成评测报告；人工只需确认授权与最终真值。
