# iCAN 智慧教育参赛版交付说明

## 产品闭环

教师上传完整 SOP 教学视频，系统生成可编辑的步骤草稿。教师校对时间片段、学习目标、完成条件、纠错提示与课程信息后发布。学生逐步观看示范并使用电脑摄像头练习；普通步骤以覆盖至少 1 秒的三帧画面调用一次多模态 API，通过后进入下一步。关键或安全步骤要求两轮新画面确认。看不清时自动补拍，明确错误时显示条件对应的修正提示。

教师可在“班级学情”查看完成率、视觉核验调用量、共性薄弱步骤和单次报告。学生完成后可查看完成率、练习指数、每步耗时、纠错与建议复习项。练习指数只由系统记录计算，不等同于真实掌握度。

## 赛场启动

```powershell
.\scripts\Prepare-Contest.ps1 -Reset
.\scripts\Start-Contest.ps1
```

账号与停止方式见根目录 `DEMO.md`。赛前应运行教师端“数据与模型”中的 Provider 能力探测。若网络或 API 故障，打开学生账号的预置完成记录，页面会明确标注“工程回放”。

## 已知限制

项目没有真人用户测试，不能声明学习效果、泛化准确率或课堂规模化效果。三组公开视频测试属于同源回放。折纸杯素材仅限本地功能 QA，不进入公开参赛材料。旧源码包曾包含已经移除的数据集适配实验测试；当前 CI 以实际交付的 Web、SOP、陪练、考评、安全和迁移模块为准，历史测试清单记录在开发日志中。

参赛材料由团队在 AI 工具辅助下整理，关键产品决策、教师发布门禁、验证口径和最终内容由团队审核。
