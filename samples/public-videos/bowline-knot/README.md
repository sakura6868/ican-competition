# NPS 单套结教学测试素材

完整公开视频已下载到本目录 `nps-bowline-720p.mp4`。来源、许可说明及文件校验值见 `source.json` 和 `ATTRIBUTION.txt`。

[来源页面与公开下载入口](https://www.nps.gov/media/video/view.htm?id=E5715EC7-6AE4-4928-BFCE-1B9F2B2D5DBF) · [本次测试记录](../../../docs/PUBLIC_VIDEO_TEST_2026-10-15.md)

`results/generated-sop.json` 是真实模型生成的未确认草稿；`results/reviewed-sop.json` 是隔离测试用的校对配置；`results/practice-results.json` 是真实视频帧回放核验结果。`observations/` 中图片均从原视频提取，文件名标有源时间。联系表中的黑色格子只是末行空位。

视频受项目现有媒体忽略规则保护，不会随源码发布包自动分发。此目录结果不代表真人学员的准确率测试。
